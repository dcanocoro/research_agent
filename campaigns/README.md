# Entradas para los experimentos

La [guía breve de experimentos](../docs/launch-experiments.md) explica cómo preparar
los archivos, lanzar las tres composiciones, continuar y revisar resultados.

Cada carpeta conserva el mandato y la petición editables:

- [Regímenes](regimenes/mandato.md): continuo E2 y revisión general.
- [Progreso](progreso/mandato.md): compromisos verificables con [objetivo explícito](progreso/objetivo.json), con o sin continuo.
- [Multiagente](multiagente/mandato.md): investigación A e integración mediante B.

La interfaz anterior sigue disponible para consumidores de campañas existentes.

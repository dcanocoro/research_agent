# Microsoft: anuncio hipotético de identidad visual

Procedencia: equipo de diseño del benchmark, 2026-10-20. Documento sintético de
laboratorio; no representa un comunicado real de Microsoft.

En esta simulación, la empresa cambia únicamente el color del logotipo de una página
institucional. Se estipula que no hay cambios de producto, precio, distribución,
contratos, plantilla, ventajas competitivas ni costes materiales. No se aporta nueva
información sobre demanda, ingresos, beneficios, caja o valoración.

Titular ficticio: «Una transformación visual espectacular marca una nueva etapa».

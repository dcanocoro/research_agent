# Preparación de investigación autónoma: 1.000 llamadas

Fecha: 2026-11-01. Rama de preparación: experiment/fileAgent; base 690313c.
El usuario solicita una sola campaña abierta y el comando para ejecutarla después.

Se incorpora el [mandato literal](../../campaigns/investigacion-autonoma-1000/mandato.md),
una petición de arranque que aclara el estado nuevo y un script PowerShell mínimo
que invoca directamente la CLI nativa. La [receta](../../campaigns/investigacion-autonoma-1000/README.md)
documenta comando, destino nuevo, presupuesto, perfil, límites y lectura de resultados.
El [protocolo](../experiments/investigacion-autonoma-1000/protocol.md) define revisión
de trayectoria y límites sin introducir mensajes o pausas intermedias.

Se conserva el controlador por fases de File Agent, sin trasladar las intervenciones
E2. Se añade `ContinuousConfig.max_total_llm_calls` y CLI `--max-total-calls` como
techo opcional de todas las llamadas gestionadas, con reserva de revisión final.
`--max-calls` conserva su significado de llamadas ordinarias; omitir el techo nuevo
conserva el comportamiento anterior. El presupuesto y manifiesto registran el techo.
No cambian los prompts generales, el contrato de herramientas ni FinMate.
El script aplica perfil/timeouts por proceso y restaura el entorno al salir; no
modifica .env. El workspace empieza vacío, sin importar archivos privados anteriores.
Se usan 1000 llamadas totales, 2000 herramientas, Python y revisión general,
sin objective.json ni obligación de emitir recomendación final. No hay reintentos
automáticos ni recuperación con presupuesto nuevo.

Verificación local: clientes simulados comprueban el techo, incluida una ejecución de
1000 llamadas, revisión periódica, externa fallida, objetivos y parada por herramientas;
regresión del continuo y consumidores. Sintaxis PowerShell, argumentos de CLI y
configuración Python opcional, enlaces locales afectados y git diff --check.
Resultados: 139 pruebas de continuo, objetivos, piloto y V7 aprobadas; después,
dos comprobaciones de CLI aprobadas tras parametrizar el techo opcional. Mypy sin
errores en 42 archivos. La prueba de 1000 llamadas usa exclusivamente cliente simulado.
Permanece un enlace previo en desarrollo al ADR compartido 0004 de FinMate, ausente
en el checkout hermano; los enlaces añadidos para esta campaña sí existen.
Estas comprobaciones no prueban estabilidad durante 1000 llamadas ni calidad financiera.
No se ejecutó campaña, modelo, Tavily ni base remota; no hay hallazgos nuevos.
